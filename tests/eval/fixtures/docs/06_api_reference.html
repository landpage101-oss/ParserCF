API Reference

The JsonParser class provides a high-level interface for parsing and serialising JSON documents with configurable strictness.

class JsonParser

class JsonParser(strict: bool = True, max_depth: int = 128)

Creates a new parser instance. Set strict=False to allow trailing commas and C-style comments in the input.

Parameters

  • strict (bool, default True) — Enforce strict RFC 7159 syntax. Disable only for hand-authored config files.
  • max_depth (int, default 128) — Maximum nesting depth. Raises DepthError if exceeded.
  • encoding (str, default "utf-8") — Expected byte-string encoding when parse_bytes() is called.

JsonParser.parse

def parse(text: str) -> Any

Parse a JSON string and return the corresponding Python object. Raises ParseError on malformed input, DepthError if nesting exceeds max_depth.

Example

parser = JsonParser()
data = parser.parse('{"version": 2, "items": [1, 2, 3]}')
print(data["version"])  # 2

JsonParser.dumps

def dumps(obj: Any, *, indent: int | None = None) -> str

Serialise a Python object to a JSON string. Pass indent for pretty-printed output.

Errors

  • SerialiseError — Raised when obj contains a type that has no JSON representation (e.g. datetime without a custom encoder).
