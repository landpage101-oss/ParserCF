Low-level API

The low-level streaming API provides direct control over StreamReader and StreamWriter objects without the convenience wrappers.

Library

The standard library module asyncio ships with Python 3.4+. No external dependencies are required.

Concurrency primitives

asyncio builds on top of an event loop that multiplexes I/O across coroutines without OS-level threading overhead.

asyncio Streams

Streams are high-level async/await primitives built on top of the lower-level transport and protocol interfaces.

Low-level API details

At the lowest layer, you obtain a transport and protocol pair by calling loop.create_connection() directly. This gives maximum flexibility at the cost of boilerplate.

import asyncio

class EchoClientProtocol(asyncio.Protocol):
    def connection_made(self, transport):
        self.transport = transport
        transport.write(b"Hello!\n")

    def data_received(self, data):
        print(f"Received: {data.decode()}")

    def connection_lost(self, exc):
        asyncio.get_event_loop().stop()

Call loop.run_until_complete() to drive the event loop until the coroutine completes.

loop = asyncio.get_event_loop()
coro = loop.create_connection(EchoClientProtocol, "127.0.0.1", 8888)
loop.run_until_complete(coro)
loop.run_forever()
