Memoization

Memoization is an optimisation technique that stores (caches) the results of expensive function calls and returns the cached result when the same inputs occur again. It trades memory for speed and is a specific form of dynamic programming.

Code examples

  • Python — built-in decorator: 
    from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
  • Python — manual dict cache: 
    _cache = {}

def fib(n):
    if n not in _cache:
        _cache[n] = n if n < 2 else fib(n - 1) + fib(n - 2)
    return _cache[n]
  • JavaScript — closure cache: 
    const memo = fn => {
  const cache = {};
  return (...args) => cache[args] ?? (cache[args] = fn(...args));
};
