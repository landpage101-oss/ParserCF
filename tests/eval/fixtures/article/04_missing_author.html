Getting Started with SQLite in Python

SQLite is a lightweight, serverless relational database that ships with Python's standard library. No installation required — import sqlite3 and start storing data immediately.

Creating a Connection

Open a connection to a database file with sqlite3.connect(). Pass ":memory:" for an in-memory database ideal for tests and ephemeral state that should not persist between runs.

Executing Queries

Use a cursor from connection.cursor() to execute SQL statements. Always prefer parameterised queries with ? placeholders to prevent SQL injection. Call connection.commit() after any INSERT, UPDATE, or DELETE statement.

Context Manager Protocol

The connection object supports the with statement: a successful block auto-commits the transaction; an exception triggers an automatic rollback. This makes transaction management concise and correct without boilerplate.

SQLite handles most single-writer workloads without any external service dependency, making it the ideal starting point for CLI tools, embedded applications, and early-stage products.
